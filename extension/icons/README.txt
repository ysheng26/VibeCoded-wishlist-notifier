ICONS REQUIRED

You need to create three icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

Quick way to create icons:
1. Go to: https://favicon.io/emoji-favicons/heart-with-ribbon/
2. Download the ZIP
3. Use the generated PNGs and resize as needed

Or create your own using any image editor!
