# Overview

This project is to create a solution when Men browse sites like Micro Center, Amazon, Steam to punch in their significant other's email and an email would be sent with words like: your loved XXX is really looking for YYY etc etc.

The email should be in HTML format, maybe some template text and the screenshot of the thing.


I would like a go lang backend server that handles the email part, maybe a chrome plugin that detects websites and has website specific code to pull out the image then send to the backend server. Ofcourse the chrome plugin needs to take the receiver email


I'm going to use everything for free, so for the email let's assume that I have a new gmail account and we would use that smtp server.

The extension should store multiple emails

the email style should be subtle and sweet
